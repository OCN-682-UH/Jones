Investigating Cheeses

Is cheese a healthy part of a balanced diet?

I really love cheese, so I want to play with some data that will support my cheese consumption habits by showing cheese is part of a healthy, balanced diet. Cheese contains calcium, which supports bone and dental structure and density, proper muscle contraction, and nerve cell communication. With many folks opting for oat milk or other substitutes over regular milk these days, cheese provides a solid option to maintain the daily dose of 1,000 mg of calcium per day recommended by the NIH.

Wait, wait, wait, that plot does a TERRIBLE job of showing us how much calcium content is in each type of cheese.

It breaks SO many rules. It is:

  • Hard to read due to cramped labels and the lack of a title, so you have to look at the caption to understand what the numbers mean
  • Misleading because the color gradients are set to alphabetical order of the types of cheese and not the calcium content, so the gradient makes it seem like the darker red might have more calcium but that isn’t the case
  • Visually challenging to interpret because the angles used in a doughnut plot are not intuitive for the human brain

On top of all that, part of the data is obscured because somehow, Prince found his way onto the chart to sit right on top of the value for Castelmagno cheese while eating a cheesy Goldfish cracker! How dare he.

Let’s try this again.

clean_cheese <- clean_cheese |>
  mutate(log_calcium = log10(calcium_content))

clean_cheese |>
  ggplot(aes(x=forcats::fct_reorder(cheese,calcium_content),                    # Make a basic plot, reordered so cheese is listed by calcium content
             y=calcium_content)) +
  geom_segment(aes(xend=cheese,
                   y=min(calcium_content),
                   yend=calcium_content,
                   color=log_calcium),
               linewidth = 2) +                                                 # Turn it into a lollipop plot       
  geom_point(aes(color=log_calcium),size=4) +
  scale_color_gradientn(colors = c("#FFBB67","#FF9E27","#B16200"),              # Add a color gradient to get darker as calcium content increases
                        values = c(0,0.4,1)) +
  scale_y_log10(position="right") +                                             # Take the log of the calcium data to make it easier to visualize
  labs(title = "Calcium Content by Cheese Type",                                # Add a title, subtitle, and axes titles
       subtitle = "Data from Cheese.com",
       x = "Cheese Type", y = "log Value of Calcium Content (mg/100g)") +
  theme_minimal() +
  theme(legend.position="none",
        axis.line = element_line(color="black"),
        axis.title.x.top = element_text(margin = margin(b = 10)),
        axis.title.y = element_text(margin = margin(r = 10)),
        plot.title.position = "plot",
        plot.title = element_text(color = "#B16200", face = "bold",hjust=0),
        plot.subtitle = element_text(face = "italic",hjust=0)                   # Edit the title, subtitle, and axes titles
        ) +
  coord_flip()                                                                  # Flip the plot so the calcium content is at the top and cheeses are shown from highest to lowest calcium content, top to bottom

Much better.

This plot is much clearer and gets the point across quickly. It:

  • Has a color gradient used with intent to highlight the highest calcium content
  • Provides perceptual clarity by organizing the cheese types so you can clearly see which has the most calcium at the top
  • log transforms the data so the differences in values can be more clearly seen

It has a little less whimsy and cuteness due to the lack of Prince, but he was a bit distracting in the first plot anyways.

Now, we can all see that if we want to truly bulk up on our calcium, we just need to eat a little bit of Castelmagno each day.

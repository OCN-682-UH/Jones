Next, we need to make the column names of the county and population data match in order to join them.

## Create dataframe with population and county data in California using renaming and joining
CApop_county <- popdata |>
  select("subregion" = County, Population) |>   # Rename columns to match counties
  inner_join(counties) |>
  filter(region == "california")                # Make sure it reads only counties from California, since some county names repeat in other states

Now that we have our joined data of population and counties within California, we will make a map of California with the dataframe we just created.

## Create a map of California with population by county
ggplot() +
  geom_polygon(data = CApop_county,
               aes(x = long, y = lat,
                   group = group,
                   fill = Population),
               color = "black") +
  coord_map() +
  theme_void() +
  scale_fill_gradient(transform = "log10")   # Use log10 to compress the color scale so less-populated counties are still visible alongside Los Angeles
